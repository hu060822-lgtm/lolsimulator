# 財務、贊助與教練團（Phase 2）

## 收入與支出

| 收入 | 計算（每年，按週入帳） |
|---|---|
| 聯賽分潤 | 聯賽 `format.revenue_share`（預設 250,000） |
| 贊助 | 生效中贊助合約的年度金額合計 |
| 周邊商品 | 粉絲數 × 0.5 |
| 直播與媒體 | 聲望² × 60 |
| 獎金 / 贊助績效獎金 | 賽季結束時發放 |
| 轉會收入 | 賣出選手時 |

支出：選手薪資、員工薪資、營運成本（150,000 + 聲望 × 10,000 + 粉絲 × 0.1）、轉會支出、員工解約補償（剩餘合約 × 50%）、球探費用（每次 $15,000）。

每季帳本在 `club.ledger`，賽季結束時封存到 `club.finance_log`（保留 15 年）。帳本淨額恆等於資金變化（測試 `test_weekly_ledger_records_income_and_wages`）。

## 贊助

- 三個位置：主贊助、服裝贊助、合作夥伴；金額基準 = 50,000 + 聲望 × 13,000 + 粉絲 × 0.15，再乘上位置係數（1.0 / 0.35 / 0.2）。
- 合約到期的位置在休賽季第 1 天收到三種報價：
  - **穩定型**：全額保底、一年。
  - **績效型**：保底 70%，奪冠再拿 90%，進季後賽或達到目標名次再拿 35%。
  - **長約型**：保底 90%、三年，鎖定收入但無法隨聲望上漲重談。
- 玩家在「財務」頁面選擇；開季前沒選的位置自動簽穩定型。AI 依經營方向選擇（爭冠 → 績效型、培養/性價比 → 長約型）。

## 粉絲

賽季結束：粉絲 × (1 + (名次分數 − 0.45) × 0.12 + 奪冠 0.15) + 聲望 × 300。

## 教練團

| 職位 | 主要能力 | 影響 |
|---|---|---|
| 主教練 | 全部 | 基礎值 |
| 助理教練 | 戰術、培養 | 選手成長速度、選手對「個人成長」的滿意度、比賽戰術 |
| 數據分析師 | 禁選、臨場調整 | 禁選品質、禁選演練效果、系列賽與比賽中的調整 |
| 體能心理教練 | 體能心理、管理 | 每週疲勞與壓力恢復 |
| 球探 | 眼光 | 每週對其他選手的認識速度、派球探的效果 |

**有效能力 = 主教練 + max(專職員工 − 主教練, 0) × 0.5**：沒請專職員工不會變弱，請到比主教練強的人才有加成。

- 員工要求年薪依主要能力與聲望；聲望明顯高於俱樂部的人需要加薪才肯來。
- 合約到期：玩家的員工自動續一年；AI 的員工 55% 續約，否則回到市場。62 歲以上的閒置員工退休，市場每年補充新人（每職位至少 8 人）。
- AI 在休賽季第 7 天補齊空缺（員工薪資預算為選手薪資預算的 18%），依經營方向決定先請誰；排名遠低於預期時解雇主教練。
- 主教練只能在休賽季解雇。
- AI 俱樂部賽季結算時，現金超過 3 倍薪資預算的部分有 25% 作為投資方分紅流出（玩家俱樂部不受影響）。
