# 規則 06：轉會市場與合約（Phase 1 基本版）

> 實作：`src/systems/transfer/transfer_market.gd`

## 1. 市場價值（不等於轉會費）

```
價值 = 8000 × 1.10^(CA − 40)
     × 年輕溢價（≤21 歲：1 + max(潛力 − CA, 0)/40）
     × 老化折價（≥27 歲：每歲 −12%，最低 25%）
     × 合約年限（0.5 + 0.25 × 剩餘年數）
     × 知名度（0.8 + 知名度/250）
```

## 2. 薪資要求

```
要求 = (18000 + 7000 × 1.075^(CA − 40)) × (0.85 + 知名度/300) × (MONEY 目標 ×1.15)
```

## 3. 要價（賣方）

- 先發選手 × 1.5
- 已要求離隊 × 0.7
- 若有解約金，最多等於解約金

## 4. 流程

```
自由球員：offer_contract → 選手合約效用判斷 → 簽約
有合約者：make_transfer_offer
  → 賣方是玩家？ → 收件匣（等待玩家回覆）
  → 轉會費 ≥ 要價 且 買方現金足夠？
  → 選手合約效用判斷（規則 02 §5）
  → 完成：名單、現金、合約、歷史紀錄
```

拒絕會記錄原因：「薪資不足」「球隊競爭力不足」「出場承諾不夠」「不願意留在這支隊伍」「不想離開家鄉賽區」。

## 5. 合約條款

P1：年薪、起訖年份、出場承諾（starter/rotation/backup/prospect）、簽約金、解約金、勝場獎金。
P2 擴充：出場條件、冠軍/MVP 獎金、續約選項、轉會限制、經紀人。
