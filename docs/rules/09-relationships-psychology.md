# 關係網絡與選手心理（Phase 2）

## 關係值

- 每對選手、每位選手與主教練之間有一個關係值（-100..100），存在 `WorldState.relations`。
- 第一次成為隊友時，依**相容度**建立（相容度 × 0.6）：
  - 同國籍 +12；年齡差每歲 −1.2
  - 雙方團隊合作、情緒穩定越高越好
  - 兩個野心都 > 75 的人 −10（互相較勁）；同位置 −8（搶先發）
- 與主教練的初始關係取決於主教練的「管理」能力。
- 選手轉隊時清除舊關係。

| 關係值 | 標籤 |
|---|---|
| ≥ 60 | 摯友 |
| ≥ 40 | 好友 |
| ≥ 10 | 融洽 |
| −10..10 | 普通 |
| > −40 | 不合 |
| ≤ −40 | 交惡 |

## 每週變化（賽季中）

- 關係每週往相容度靠攏 3%。
- 訓練「團隊建立」每時段 +0.6、「Scrims」+0.1。
- 3 連勝以上：全隊 +0.5；3 連敗以上：依兩人脾氣扣分。
- 主教練關係：管理能力高者逐週改善；該先發卻坐板凳的選手 −1.2/週。
- **衝突**：關係 < −20 的兩人有機率爆發爭執（脾氣差、連敗、管理能力低時更容易），兩人士氣 −4、關係 −8、默契 −2。玩家俱樂部會收到訊息，可選擇：
  - **出面調解**：成功率取決於教練團管理能力與兩人脾氣；成功 +15 關係、+2 默契。
  - **支持先開口的一方**：一方信任 +8，另一方信任 −12、與主教練關係 −10。
  - **不介入**：默契 −1。
- **老將指導**：25 歲以上、職業態度 ≥ 65 的老將，會讓關係融洽的 20 歲以下隊友理解型能力額外成長（同位置效果加倍）。

## 影響

- **比賽執行力**：先發五人的平均關係 × 0.15 加到默契上（最多 ±15）。
- **默契長期走向**：先發平均關係 / 100 × 0.5 每週。
- **滿意度**：新增「人際關係」面向（權重 0.35 + 團隊合作/200）；有交惡隊友時 −0.4。人際關係太差的選手會找你談，甚至要求離隊。

## 選手心理

- **連勝 / 連敗**（`club.streak`）：3 連勝以上先發自信 +1.5/系列賽；3 連敗以上壓力上升、自信下降、與主教練關係下降。
- **局間情緒（tilt）**：系列賽輸掉一局，下一局每位選手狀態 −(1 − 抗壓性/100) × 0.06；贏下一局即消除。
- **大賽經驗**：季後賽（stakes ≥ 1.5）每打一個系列賽 +1；大賽壓力的影響最多降低一半（60 場時）。
