# 規則 02：選手自主行為（職業生涯，而不是棋子）

> 實作：`src/systems/player/career_agent.gd`、`src/systems/transfer/transfer_market.gd`（合約效用）

## 1. 職業目標

每名選手有 1–3 個職業目標，由個性與年齡推導，每個賽季開始時重新評估：

| 目標 | 條件（摘要） | 在意的事 |
|---|---|---|
| WIN_TITLES | 野心 > 65 | 球隊競爭力、上場 |
| PLAYING_TIME | 21 歲以下 | 出場機會 |
| DEVELOP | 21 歲以下 | 教練培養能力、上場 |
| RETIRE_AT_CLUB | 忠誠 > 70 且 25 歲以上 | 對管理層的信任、留在母隊 |
| MONEY | 忠誠 < 35，或野心高但職業態度低 | 薪資 |
| GO_ABROAD | 野心 > 75 且忠誠 < 50 | 願意離開家鄉賽區、追求強隊 |
| STABILITY | 以上皆非 | 信任、薪資、上場的平衡 |

## 2. 每週自我評估

選手對五個面向打分（-1..1）：

| 面向 | 計算 |
|---|---|
| 出場機會 playing | (實際先發率 − 期待先發率) × 2。期待值取決於他在隊內同位置的 CA 排名與野心（認為自己該先發的人，坐板凳會很痛苦） |
| 薪資 salary | (年薪 / 市場薪資要求 − 1) × 2 |
| 競爭力 competitive | 俱樂部聲望 − 個人野心 |
| 信任 trust | 對管理層的信任（承諾是否兌現、溝通方式） |
| 發展 development | 教練培養能力 + 出場 |

**滿意度** = 依職業目標加權的平均，再以指數移動平均平滑（不會因一週就翻臉）。
同樣的處境，PLAYING_TIME 的新人與 MONEY 的老將感受完全不同。

## 3. 選手主動採取的行動

| 觸發 | 行動 | 對玩家的呈現 |
|---|---|---|
| 滿意度 < `talk_threshold`（-0.25） | 要求談話，指出最不滿的面向 | 收件匣訊息 + 回應選項 |
| 滿意度 < `transfer_request_threshold`（-0.45）連續 4 週 | **正式要求離隊**（`transfer_requested`） | 收件匣 + 事件紀錄（含原因）；要價自動降低 30% |
| 合約最後一年且不滿（或 GO_ABROAD 且球隊競爭力不足） | **拒絕續約**（`refuses_renewal`） | 續約效用中「忠誠」變為 -1 |
| 賽季結束 | **退役判斷** | 見 §6 |

AI 俱樂部遇到同樣的情況，使用同一套回應函式。

## 4. 回應與承諾（領導力系統雛形）

玩家回應的效果取決於選手的個性與信任，**不是固定加減**：

| 回應 | 效果 |
|---|---|
| 承諾出場時間 | 滿意度 +0.25×(0.5+信任)，並建立 6 週的承諾。到期時先發率 ≥ 60% → 信任 +10；否則信任 −22、滿意度 −0.3 |
| 解釋球隊狀況 | 信任高的選手接受；信任低的選手覺得是藉口（效果可能為負） |
| 要求耐心 | 情緒穩定的選手能接受；情緒化的選手更不滿，並降低信任 |
| 放上轉會名單 | 不滿的選手滿意；滿意的選手覺得被拋棄 |
| 無視 | 滿意度 −0.25、信任 −12 |

第四階段的完整對話系統會在這個基礎上加入上下文（近期比賽、過往承諾、隊友關係）與「對話成果」（得知衝突、戰術建議等）。

## 5. 合約效用：選手怎麼選下家

```
效用 = 加權平均(
  money       = (年薪/要求 − 1) × 2.5,
  competitive = (俱樂部聲望 − 50)/50,
  playing     = 先發 0.8 / 輪替 0 / 替補 −0.6 / 新秀 −0.2(19 歲以下),
  loyalty     = 是現役俱樂部時 = 忠誠/100（拒絕續約時 = −1）,
  home        = 同賽區 +0.25 / 跨賽區 −0.3（GO_ABROAD 反而 +0.3）
) × 2
```

權重由目標調整（MONEY +1.5 money、WIN_TITLES +1.2 competitive、RETIRE_AT_CLUB +2.5 loyalty…）。
接受門檻：自由球員 −0.15；續約 0；離開現役俱樂部 +0.1。

測試 `test_loyal_veteran_rejects_bigger_offer_abroad`：28 歲、忠誠 95、目標 RETIRE_AT_CLUB 的老將，
面對跨賽區 +40% 薪資仍選擇留隊；同隊 MONEY 型選手則選擇離開。

## 6. 退役

賽季結束時，26 歲以上：

```
機率 = (年齡 − 26) × 0.06 + max(55 − CA, 0) × 0.015 + max(50 − 動機, 0) × 0.004
     + 無球隊 0.2 + (RETIRE_AT_CLUB 且合約到期 0.15) − (WIN_TITLES 且從未奪冠 0.1)
```

因此：沒拿過冠軍的老將會想再拚一年；想在母隊退役的選手合約結束時傾向就此退休；
在巔峰時期選擇退休也會偶爾發生（GDD 20）。

## 7. 可追溯性

所有行動都寫入 `WorldState.log`，帶有原因：
`transfer_request`（連續 N 週不滿、最不滿面向）、`player_concern`、`refuses_renewal`、
`promise_kept` / `promise_broken`、`player_talk`、`contract_offer`（接受/拒絕原因）、`retirement`。
